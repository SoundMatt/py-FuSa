# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 0.3.x | ✅ |

## Reporting a Vulnerability

Report security vulnerabilities by opening a private advisory at
https://github.com/SoundMatt/py-FuSa/security/advisories/new

Please include:
- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Suggested remediation (if known)

We aim to respond within 5 business days and to publish a fix within 30 days of confirmed receipt.
